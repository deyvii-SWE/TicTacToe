# TicTacToe (Jogo em Python)

Um jogo simples de TicTacToe desenvolvido em Python, utilizando classes e funções. O código está documentado para facilitar sua compreensão.

## Como o Jogo Funciona?

É TicTacToe! Nunca jogou antes? Sem problemas, eu te explico!

O objetivo é ser o primeiro jogador a alinhar três X's ou O's em uma linha. Você pode fazer isso horizontalmente, verticalmente ou diagonalmente.

Se todos os espaços forem preenchidos e ninguém conseguir alinhar três símbolos, o jogo termina em empate. Nenhum ponto é concedido, e o tabuleiro é reiniciado para a próxima rodada.

## Sobre o Código

Utilizei uma classe para lidar com a interface do console e tentei manter o código o mais limpo e legível possível. Também experimentei list comprehensions e one-liners para tornar algumas partes do código mais concisas.

O jogo atualmente possui dois modos:

- **PvP (Player vs. Player)**: Jogue contra outra pessoa.
- **PvE (Player vs. Environment)**: Jogue contra o computador.

O computador ainda não possui nenhuma IA, mas pretendo implementá-la no futuro! Por enquanto, ele simplesmente coloca um "O" em uma posição aleatória disponível, então é bem fácil de derrotar.

Também existem dois modos de jogo:

- **One Shot**: O primeiro jogador a vencer ganha a partida.
- **3 Rounds**: Um formato de melhor de três. O primeiro jogador a vencer duas rodadas ganha a partida. Empates não contam para o limite de rodadas, então, se o placar estiver em 1-1, haverá uma rodada final para decidir o vencedor.
